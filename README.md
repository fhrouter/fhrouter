# FHRouter

FHRouter provides access to Claude, GPT, and Gemini models through one API key and a prepaid balance. Check the [current catalog](https://fhrouter.com/pricing) for model availability, supported endpoints, and prices. Requests use your account balance; these examples do not include free inference.

Use the OpenAI-compatible endpoint at `https://fhrouter.com/v1`, or follow the native-endpoint guides for [Claude Code](https://fhrouter.com/docs/guides/claude-code), [Codex CLI](https://fhrouter.com/docs/guides/codex), and [Gemini CLI](https://fhrouter.com/docs/guides/gemini).

## Get started

1. [Create an account](https://fhrouter.com/register) and add credit.
2. Create an API key in the console.
3. Select a model from the catalog and follow the [quickstart](https://fhrouter.com/docs/quickstart).

This repository contains service information and links. Runnable examples are available in the [FHRouter organization](https://github.com/fhrouter).
